**Title:** Hospital Management System Database Infrastructure — A Mini Version

**Date:** 09/2026

**Status:** Accepted

**Owner:** Alicya e Monique

**Context:** Uma infraestrutura relacional projetada para suprir com eficiência as demandas de um sistema hospitalar/clínico (médicos, especialidades, pacientes, consultas, prontuários e prescrições), apresentada de forma simplificada e modular.

**Decision:** Opta-se por disponibilizar o ambiente pré-configurado para execução e estudo. Na branch do repositório/máquina virtual, inclui-se o Linux configurado com banco de dados para gerenciamento das tabelas hospitalares, pronto para execução de scripts DDL/DML e consultas integradas. O script foi documentado em Bloco de Notas e executado diretamente via prompt de comando (terminal). As credenciais padrão para ambiente de testes são:

Acesso à VM: saas / saas

Acesso ao Banco de Dados: saas / saas

Servidor Web/Aplicação: admin / saas

O banco de dados está liberado para conexões e execuções via prompt de comando da máquina.

**Consequences:** O utilizador dispõe de uma estrutura de dados relacional pronta para gerenciar fluxos médicos, realizar consultas parametrizadas e migrar a base para novos ambientes conforme a necessidade.
